使用方法

  1. 把游戏文件夹拖进窗口，或点击选择（自动识别文件编码，日文游戏无需手动转码）
  2. 扫描到 .xp3 资源包：点「解包并翻译」，包内文本会加入文件列表（标记【xp3】）
  3. 勾选文本文件 → 「提取并翻译」
  4. 左侧文件树查看译文，顶部切换 仅原文 / 对照 / 仅译文
  5. 「导出」下载 zip（保持原编码）；解包过的资源包可「封包为 xp3」（原包自行备份后替换）

翻译引擎

  • MyMemory：免费，无需配置，有每日额度
  • 百度翻译：国内稳定，免费额度，需 APP ID + 密钥
  • DeepL：需 API Key
  • OpenAI 兼容：本地 LLM（Ollama / LM Studio 等）

常见问题

  • Windows 提示“未知发布者”？点「更多信息 → 仍要运行」，程序没有病毒
  • 杀毒软件报警？属误报，添加信任即可
  • 译文中文显示为方块？原日文编码装不下中文时已自动转存 UTF-8，游戏可能需要中文字库
  • 加密的 xp3 暂不支持（会提示“已加密”）
  • 所有处理在本机完成，游戏文件不会被上传到任何服务器
