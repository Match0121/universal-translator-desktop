## 项目基本信息

- 软件名称：万能翻译站（Universal Translator）
- 开源地址：https://github.com/Match0121/universal-translator-desktop
- 开源协议：MIT
- 平台：Windows 10/11 桌面
- 语言：Python + pywebview + 原生前端（ES Modules），无构建依赖

## 详细介绍

万能翻译站是一个 Windows 桌面万能文本翻译工具，目标很直接：不用在文件管理器与多种翻译软件之间挣扎，将文件拖入框内，不管是文件、游戏还是图片，识别、提取、翻译、替换，一个平台解决所有烦恼。当前文本文件与游戏文本的完整链路已经实现，文档翻译与图片翻译在规划中。

从开发者角度看，游戏文本场景集中体现了两类真实问题：

一是编码问题。日文游戏剧本多为 Shift-JIS 编码，主流编辑器按 UTF-8 读取会乱码，手动转码繁琐。工具内置编码自动检测，通过 BOM 识别、UTF-8 严格校验、假名分布投票三层判断，自动区分 UTF-8 / UTF-16 / Shift-JIS / GBK，日文剧本直接拖入即可提取。

二是资源打包问题。吉里吉里（KiriKiri）引擎的游戏把剧本封装在 xp3 资源包里，普通文本扫描工具看不到内容。工具实现了 xp3 的解包与封包（参照 krkrz 开源 SDK 的格式规范），扫描到资源包后可一键解包，包内文本进入同一套翻译流程，翻译完成后按原格式重新封包。

提取层面采用行级单元模型，支持 txt / json / ini / srt / ass / rpy（Ren'Py）/ ks（吉里吉里，含日文「」『』引号）等格式，提取与写回共用同一套定位，因此天然支持原文/对照/译文三态切换和原编码导出。翻译引擎可切换 MyMemory（免费）、百度、DeepL、OpenAI 兼容接口（可接本地 LLM）。

产品形态为 PyInstaller 打包的单文件绿色 exe，双击即用，无需安装 Python 或其他依赖；翻译处理全部在本机完成，文件不出电脑。界面为自定义设计的高级简约风格，支持浅色/深色双主题。
