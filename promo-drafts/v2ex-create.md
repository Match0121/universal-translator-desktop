Title: 我用 Python 写了个把文件拖进去就自动翻译的桌面工具（不止游戏）

起因是某天想玩个日文 galgame，打开目录一看，剧本全是 Shift-JIS 编码的 .ks 文件，文本编辑器里全是乱码；更麻烦的是剧本还锁在 data.xp3 资源包里，想翻译得先解包、转码、逐句找翻译软件来回切。折腾一晚上后我决定干脆写个工具把这些事一次做完。

做着做着发现这个思路可以做大：翻译文本本来就该是"把文件拖进去就行"的事，不用在文件管理器与多种翻译软件之间挣扎。于是定位成了万能文本翻译工具（https://github.com/Match0121/universal-translator-desktop，MIT）：不管是文件、游戏还是图片，识别、提取、翻译、替换，一个平台解决。

目前已经实现的：

- 文本文件翻译：txt / json / ini / srt / ass 等格式拖入即译
- 游戏翻译：自动识别引擎，日文 Shift-JIS 剧本免转码直接提取
- 吉里吉里 xp3 一键解包，翻译完再封包回去
- Ren'Py rpy / 吉里吉里 ks 剧本支持，含日文「」引号
- 翻译引擎可切 MyMemory / 百度 / DeepL / 本地 LLM
- 打包成单文件 exe，绿色免安装，翻译全在本地跑
- 文档翻译、图片翻译在规划中

自己实测翻了个 BepInEx 模组说明和几个游戏剧本，对照视图左边原文右边译文，体验还行。日文游戏汉化折腾过的人应该懂这个痛点。
