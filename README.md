# Universal Translator · 桌面版

游戏文本翻译工具（Windows 桌面应用）。拖入游戏文件夹 → 自动扫描文本 → 翻译成中文 → 按文件查看译文 → 导出。

**与 Web 版的关系**：桌面版 v1.1 起**独立迭代**（Web 版维持 v1.0 原样）。前端代码维护在本项目 `web/` 目录，不再依赖 Web 版同步。

## 分发给用户（只需一个文件）

把 `dist\UniversalTranslator.exe`（约 10MB，绿色单文件）发给用户即可，**用户无需安装 Python、无需浏览器、无需任何依赖**。使用说明已内置在应用内：右上角 ⚙ 设置 → 使用说明 / 更新日志。

**用户须知**：
- 系统要求：Windows 10 / 11
- 首次双击启动会慢几秒（单文件解压），属正常现象
- 若 Windows 提示"未知发布者"：点「更多信息 → 仍要运行」（未做代码签名，属个人开发者常态）
- 个别杀毒软件可能误报，添加信任即可
- 所有处理在本机完成，游戏文件不出电脑；关闭窗口即退出

**更新版本**：重新打包新的 exe 发过去，用户直接覆盖替换即可。

## 支持翻译的文件

**文本文件（明文，引擎无关）**：`txt` / `md` / `log` / `story` / `script` / `json` / `xml` / `yaml` / `yml` / `ini` / `cfg` / `conf` / `srt` / `ass` / `ssa`

**游戏剧本**：
- `rpy`（Ren'Py 引擎，引号内文本）
- `ks`（吉里吉里 KiriKiri 引擎，支持日文「」『』引号）

**资源包**：吉里吉里 `xp3` —— 可解包 → 翻译包内文本 → 重新封包回写（加密包不支持，会提示“已加密”）

**编码自动识别**：UTF-8 / UTF-16 / Shift-JIS（日文游戏）/ GBK（中文游戏），无需手动转码。

**暂不支持**：图片中的文字（菜单/CG 气泡）、Unity/Unreal 等引擎的资源包（assets/pak）、程序内嵌字符串、RPG Maker VX/Ace 的 .rxdata 二进制数据。

**判断方法**：授权文件夹后看扫描结果——扫出 txt/json/ks/rpy 等就能翻；只有几个几百 MB 的大包（xp3/assets/pak）则文本在包内，目前仅 xp3 支持解包。

## 使用（最终用户操作）

1. 双击 `UniversalTranslator.exe`，应用窗口打开
2. 拖入游戏文件夹，或点击选择（自动识别文件编码：UTF-8 / Shift-JIS / GBK / UTF-16，日文游戏无需手动转码）
3. 若扫描到 `.xp3` 资源包：点「解包并翻译」，包内文本会加入文件列表（标记【xp3】）
4. 勾选文本文件 → 提取并翻译（翻译引擎在右上角设置里选择）
5. 左侧文件树查看翻译结果，顶部切换 仅原文 / 对照 / 仅译文
6. 导出 zip（保持原编码写回；原编码装不下译文时自动转存 UTF-8 并提示）
7. 解包过的资源包：点「封包为 xp3」生成新的 xp3，备份原包后替换即可（加密包不支持）

## 开发模式（给开发者）

```powershell
pip install pywebview
python desktop.py
```

内嵌窗口不可用时自动回退到系统浏览器（功能不变）。

## 打包

```powershell
双击 build.bat
# 产物: dist\UniversalTranslator.exe（绿色单文件，约 10MB）
```

## 翻译引擎

| 引擎 | 说明 |
| --- | --- |
| MyMemory | 免费，无需配置，有每日额度 |
| 百度翻译 | 国内稳定，免费额度，需 APP ID + 密钥（设置里填写，本地代理中转） |
| DeepL | 需 API Key |
| OpenAI 兼容接口 | 本地 LLM（Ollama / LM Studio 等） |
